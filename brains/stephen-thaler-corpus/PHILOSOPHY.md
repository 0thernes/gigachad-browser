# Philosophy — Thaler Study Corpus

## Core stance

Thaler’s program is treated as **mechanism-first cognitive architecture**:
perturbation → confabulation stream → second-net appraisal → (optional) affective
hot-buttons → selection / reinforcement. That is a **buildable** story.

## Binding honesty

| Allowed | Forbidden |
| --- | --- |
| “Operational reimplementation of Thaler-style generator/critic” | “Is conscious” |
| “Meets coded constitutive markers under ensemble protocol” | “Proves phenomenal sentience” |
| “Publicly described in patent X / paper Y as cited” | “Dr. Thaler endorses Cosmogonic” |
| “Study notes for RAG / agent harnesses” | Full-text PDF piracy |

## Why Thaler is first

Among consciousness-adjacent engineers, Thaler’s line is unusually **compact,
patented, and phenomenon-driven** (virtual input, life-review under damage,
glory/sweet-spot regime, madness–creativity cycles, DABUS inventorship battles).
That makes it the right **first** deep corpus before IIT, GNW, FEP, AST, etc.

## RAG purpose

LLMs and multi-agent harnesses should retrieve **paper-local doctrine**, not
vibes. Every dossier’s 8 documents answer a different retrieval intent:

1. **README** — what is this work?
2. **SUMMARY** — what should I remember in 90 seconds?
3. **DETAIL** — full operator reconstruction
4. **GLOSSARY** — term definitions local to this work
5. **BIBLE** — claims the work itself treats as constitutive
6. **SPEC** — architecture / params / testable signatures
7. **INDEX** — section map + outbound citations
8. **CONNECTIONS** — Cosmogonic hooks + 9-marker map

## Maximalism with receipts

Expand the bibliography aggressively. Never invent DOI/page numbers.
If a fact is uncertain, label `confidence: low` and prefer primary links.
