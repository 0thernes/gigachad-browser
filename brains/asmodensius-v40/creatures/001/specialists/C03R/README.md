# Specialist: C03R (CQM03R ecological coupling)
Not attempted as a brain specialist: the test is ill-posed for a brain module. In tests_v37.ts evoR the number of births each generation is set by the harness rule nb = round(N*(1+tanh(mean energy balance/50))), and the score is |corr(food_t, N_{t+1})| over 7 generation points against a random-birth-number control. The coupling lives in the harness birth rule; the brain only changes energy balance, and 7-point |corr| has a large chance floor. Passing it from the brain would be gaming. A fair version needs births decided by the organism (energy-gated reproduction in organism.ts, LIFE-100 #77) with more generations.
