# V6-S1 preregistration: Blueprint A stage 1 (ORG_V6=1). Written 2026-11-01 ~09:35 PT, before any run.
Source: REARCHITECT.md section 4, Stage 1. Dev seeds only. Branch v4.0, not pushed.

## Build (ORG_V6=1 = v5.7b config [ORG_V5=11 settings] plus):
1. Plastic VSA/MAP binding hub, D=2048 binding units u*v from random projections of the centred thalamic relay rates of module pairs (0,1),(2,3), projected onto cortical E cells. Hub->cortex efficacy is a DA-RPE-consolidated gain (three-factor; starts at 0), so there is no fixed-weight helper: an RPE lesion or mixing lesion removes the hub.
2. Learned precision: decision margin scaled by policy precision pi = 1/(1 + (running |RPE| / 0.25)^2), learned online from the action-outcome error.
3. Expected-free-energy site choice: the existing v4.0 pragmatic + epistemic site term is kept unchanged (disclosed: no new EFE code in stage 1).
4. Antithetic integral appetite controller (Briat et al. 2016), k=0.3, sensed glucose = the creature's own 30-min interoceptive forecast only (aicF=1).
Flag off: byte-identical results to ORG_V5=11 required (checked on one test before runs).

## Kill criteria (any one kills stage 1)
1. AE1 pooled (64 seeds) d < 0.8 (or t < 2.75) vs RPE lesion.
2. CQM10 (C10) and C16R do not both pass on both blocks.
3. HOT3RM block-to-block d range > 0.4 (or fails either block).
4. More than 1 test that passes for v5.7b on a block is lost by v6 on that block.
Pass rule: d >= 0.8 and t >= 2.75 vs every control. No tuning after launch.
