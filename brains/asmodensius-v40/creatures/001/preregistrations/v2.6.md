## RM-10R Interoceptive prediction of energy, long-horizon evaluation (roadmap 10)
Why: frozen RM-10 (400 steps) fails at d 0.01 because iid food noise dominates the per-seed MSE; on disjoint tuning seeds 2000..2015
the same mechanism gives d 0.29 (T=400), 0.99 (T=2000), 1.68 (T=4000), 3.57 (T=10000) vs persistence. T was chosen from that power
analysis on tuning seeds only. Caveat stated up front: this is a power fix, not a new mechanism.
World: identical equations to v2.2 RM-10 but T = 10000 steps, stream mulberry(seed*211 + 2603), seeds 1000..1015.
Forecast times t in [50, T-20). Metric: -MSE of the 20-step-ahead energy forecast.
Full: efference copy of the activity schedule (exact sum of the next 20 sin-drain terms) + online food-rate estimate
(jumps/t, where a jump is E_k - expected > 0.15). Forecast = E_t - sum drain + 20*0.3*rate.
Controls: (a) persistence E_t; (b) no efference copy: E_t - 20*0.02 + 20*0.3*rate (mean drain only, same food-rate estimate).

## RM-64 Perceptual bistability (roadmap 64)
Mechanism: two rate units with mutual inhibition, slow adaptation and noise (Laing & Chow 2002 type):
r_i += dt/tau (-r_i + sig(I - beta r_j - g a_i)), a_i += dt/tau_a (-a_i + r_i), plus gaussian noise on input. Stream mulberry(seed*241+2641).
Run 40000 steps; dominance = sign(r1 - r2) with hysteresis 0.1; durations of each dominance period after the first.
Metric: gamma shape k = mean^2/var of dominance durations.
Control: memoryless (Poisson) switching with the same mean duration per seed (geometric durations, same count), stream mulberry(seed*241+2642).
Additional: every seed has >= 20 durations.
Mechanism parameters (I, beta, g, tau, tau_a, noise) may be set on tuning seeds 2000..2015 only, frozen in the code commit before the first test-seed run.

## RM-83 Latent learning (roadmap 83)
World: per-seed random perfect maze (DFS) on a 6x6 cell grid (stream mulberry(seed*251+2651)), start cell (0,0), goal cell (5,5).
Agent: learns a transition model from its own moves (wall/no wall per cell and direction); plans by BFS on the cells it believes connected
(unknown edges assumed open = optimistic); blocked moves update the model and it replans. Without a goal it explores by a random walk.
Phase 1 (full only): 1500 steps of unrewarded random-walk exploration from start (stream mulberry(seed*251+2652)).
Phase 2: the agent is placed at the goal and rewarded once (it now knows where food is), then released at start.
Metric: -(steps to reach the goal), cap 2000.
Controls: (a) naive: no phase 1 (empty model, optimistic planning); (b) wrong map: phase-1 model learned in a different maze (seed+500).
Pass rule for all: Cohen's d >= 0.8 and Welch t >= 2.75 vs every control, frozen v1 compare(), SEEDS 1000..1015.
These are small harness models of the capabilities, not behaviours of the rendered creature. A roadmap item is marked achieved only if its test passes.
