# Preregistration v2.5: CQM-21R, differentiation of the creature's own network

Frozen 2026-10-29 (Asia/Manila). Committed before any v2.5 test code was written or run. v1..v2.4 are unchanged.
The frozen v1 CQM-21 result (FAIL) stays recorded as FAIL. CQM-21R is a new, different test and is not counted as CQM-21.

## Why
Frozen v1 CQM-21 builds its own 6-unit toy network and calls no creature code, and its control (iid units) sits at the
entropy ceiling (5.985 of 6 bits). CQM-21R measures differentiation on the creature's network and uses controls that
cannot reach the ceiling.

## Network under test
The creature's 6-unit stochastic binary network `creatureNet(seed)` from harness.ts (the network the v2 tests use), with the
dynamics of `v2NetMeasures`: P(x_i=1) = sigmoid(2 h_i), h_i = b_i + inp_i + sum_j W_ij (2 x_j - 1), synchronous update.
Stimulus s in 0..7 drives units 0, 2, 4 (inp = +/-1 by bits of s). Units 1, 3, 5 get no input ("hidden units").

## Procedure (salt 2101; stream mulberry(seed*1009 + 2101))
16 seeds, 1000..1015. 200 warm-up steps with random stimuli, then 400 epochs of 25 steps. The stimulus for each epoch is drawn
uniformly from 0..7. The state carries over between epochs. Response of an epoch = the count of 1s of each hidden unit over
epoch steps 5..24 (3 numbers). Decoder: nearest class centroid (Euclidean) fitted on epochs 0..199 and tested on epochs 200..399.
Metric: differentiation = the plug-in mutual information (bits) of the 8x8 test confusion matrix, i.e. how many stimulus-specific
repertoire states the creature's recurrent dynamics produce in units the stimulus does not touch (max 3 bits, 2^I distinguishable states).
A class with no training epochs gets centroid at 0 counts.

## Controls (same stimuli and random stream layout)
(a) shuffled weights: the off-diagonal entries of W randomly permuted over the off-diagonal positions (per seed, stream mulberry(seed*1009+2102)); same b.
(b) lesioned recurrence: W = 0 (frozen state dynamics; hidden units see only their bias).
(c) iid noise matched in variance: hidden units replaced by iid Bernoulli with each unit's own marginal firing rate from the full run
    (same mean and variance), stream mulberry(seed*1009+2103).

## Pass
Cohen's d >= 0.8 and Welch t >= 2.75 vs every control, frozen v1 `compare()`.
Test code is frozen in `harness/v25tests.ts` once first run. Only the mechanism (the network the creature builds, `cqm21rNet`
in a mutable module, which initially returns creatureNet(seed) unchanged) may change, and only under a further addendum
committed before the rerun.
