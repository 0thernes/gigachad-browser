# Preregistration v2.1 — controlled tests for CQM-23, CQM-24, CQM-25

Frozen: 2026-10-28 (America/Los_Angeles), committed before any v2.1 test code was written or run.
v1 (`PREREGISTRATION.md`) and v2 (`PREREGISTRATION_v2.md`) are unchanged. Their results remain reported as they are.
Under v1, CQM-23/24/25 were "Implementation identified" (no controlled comparison). They stay reported that way under v1.

## Shared rules (same as v1/v2)
- 16 seeds, 1000..1015. mulberry32 PRNG. Pass = Cohen's d ≥ 0.8 AND Welch t ≥ 2.75 against **every** control.
- The frozen `compare()` from v1 is used. When both conditions have zero variance and the difference is positive, `compare()` returns d = t = ∞; this is accepted here and reported literally as "∞ (zero variance)".
- Tests, metrics, controls, input distributions and thresholds below are frozen. Only creature mechanisms may change, logged in `HARNESS_CHANGES.md`. No code may detect or special-case the harness.
- Where a measurement needs a browser GPU it is run in headless Chrome by `measure_gpu.js`. If no hardware GPU is available the software rasterizer (SwiftShader) is used and this is disclosed in the results. The node harness reads the recorded browser measurement file; CI without a GPU reports these comparisons from the committed record and says so.

## V2.1-23 Substrate pluralism (CQM-23)
**Function F.** The creature's 32-bit integer weight hash `hh(x)` (the one both brain kernels use to regenerate the 100M procedural weights): `x^=x>>16; x*=0x7feb352d; x^=x>>15; x*=0x846ca68b; x^=x>>16`.
**Inputs.** For seed s, 256 inputs u_k = (mulberry(s·4099+23) · 2^32) >>> 0, k = 0..255.
**Substrates.** (a) RV32I machine code executed by the creature's RV32I interpreter (RV32M `mul` permitted); (b) native JS (`Math.imul`); (c) GPU fragment shader (WebGL2, GLSL `uint` arithmetic) in headless Chrome.
**Metric.** Per seed, agreement = fraction of the 256 32-bit outputs that are bit-identical between a substrate and the JS reference.
**Comparisons.** (i) RV32I vs JS; (ii) GPU vs JS. **Mismatched-substrate control** for each: the same substrate running a mismatched program (the creature's xorshift32 step `x^=x<<13; x^=x>>>17; x^=x<<5` instead of `hh`) on the same inputs, scored against the JS `hh` reference. Expected chance agreement ≈ 2^-32.
**Additional requirement.** Every full-condition seed must have agreement exactly 1.0.
**Justification.** Substrate independence of a computation is shown by functional identity across physically different executors (Turing/Church; multiple realizability, Putnam 1967); the control rules out a scoring pipeline that reports agreement regardless of the program.

## V2.1-24 Instrumentation and reproducibility (CQM-24)
**Procedure.** For seed s, run the v2 active-inference world with the creature agent (`v2AIWorld`, CreatureAI) and the AST-1 attention task (`attnRun`, full) twice, each from a fresh `mulberry` stream. Record 64 checkpoints: the creature's belief entropy every 5 steps for 32 steps of v2AIWorld instrumentation plus the cumulative AST tracking error every 10 steps for 32 checkpoints (Float64).
**Metric.** Fraction of the 64 checkpoints whose Float64 bit patterns are identical between run 1 and run 2.
**Control (perturbed seed).** Run 2 uses seed s+1 (stream mulberry((s+1)·…)), everything else equal.
**Additional requirement.** Cross-process: `run.ts` executed twice in separate Node processes must produce byte-identical `results.json` (SHA-256 compared); reported, required for pass.
**Justification.** Reproducibility as bitwise determinism under fixed seeds (Peng 2011; Collberg & Proebsting 2016); the perturbed-seed control shows the metric is sensitive to a one-bit-scale change in initial conditions.

## V2.1-25 Visual and embodied scale (CQM-25)
**(a) Embodied degrees of freedom.** The creature's limb physics (damped Hamiltonian chains, symplectic Euler, as used on the Page) is driven for 600 steps by seeded drive signals (8 channels, AR(1) 0.95, noise 0.3). Metric: participation ratio (Σλ)²/Σλ² of the covariance of all node coordinates, i.e. effective number of independent body degrees of freedom. **Reduced-scale control:** 2 chains × 3 nodes, same drive statistics.
**(b) Rendered detail.** The Page's scene shader rendered in headless Chrome at 384×384, 16 frames, frame k uses seed 1000+k to set time T = 3 + 37·u1 and camera M = (2u2−1, 2u3−1)·0.8 with other uniforms fixed to a neutral state. Metric: mean Sobel gradient magnitude of luminance (rendered spatial detail). **Reduced-scale control:** the same shader with the scene SDF reduced to the single body ellipsoid (no limbs, spines, fin, eyes or inner organs).
**Justification.** Effective dimensionality of motor behavior (participation ratio; Gao & Ganguli 2015) and image gradient energy as a standard detail/sharpness measure (Pertuz et al. 2013).
