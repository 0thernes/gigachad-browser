# Preregistration v2.3 — live-creature organ tests (written before any run)

Committed before the tests run. The tests run the real rendered creature (src/page.tsx, which is built into site/index.html) in headless
Google Chrome (`--headless=new --dump-dom --virtual-time-budget`). The page exposes the test mode `?livetest=1&seed=S&ablate=A&frames=480`.
In test mode the creature wakes silently and runs its normal render loop. The `Organs` mechanisms (harness.ts) are stepped once per frame.
Scripted pointer events go through the canvas's real pointermove and pointerdown handlers: 20 pokes at canvas-relative (0.75,0.25),
i.e. stimulus "RU", on frames f_k = 40+4k (k=0..19), then one novel poke at (0.25,0.75), "LD", on frame 124. Light L(f) = 1 if (f mod 24) < 12, else 0.
Body readout: R(f) = the mean over the 8 limbs of the horizontal distance of the tip node, taken from the live physics state.
D(f) = R(f+3) − R(f−1).
Seeds 1000..1015. Pass: Cohen's d ≥ 0.8 and Welch t ≥ 2.75 against every listed control.

| id | score (higher is better) | controls (ablate=) |
|---|---|---|
| LIVE-80 habituation in the body | mean D(f_0..f_2) − mean D(f_17..f_19) | hab |
| LIVE-81 stimulus-specific | D(124) − mean D(f_17..f_19) | hab |
| LIVE-28 circadian entrainment | PLV of (θ_f − 2πf/24) over f = 240..480 | circ |
| LIVE-28B circadian drives the body | Pearson corr(arousal_f, R_f), f = 130..480 | circbody (arousal not applied to limb reach) |
| LIVE-47 tamper-evident lineage | detection rate over 100 single-bit tampers of the live genome chain (RV32I mutation word every 30 frames), with the adversary recomputing the record hash | chain |

The ablations change only the named mechanism. If a test cannot run (for example, no frames render headless), it is reported as NOT RUN, never as PASS.
