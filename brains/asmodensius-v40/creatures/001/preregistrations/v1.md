# Creature #1 v2 evaluation: pre-registered criteria (fixed before any run)

Seeds: 16 independent seeds per condition (seed k = 1000 + k), mulberry32 PRNG.
For every item, the "full" system is compared to EACH listed control/ablation.
A comparison passes iff BOTH:
  - effect size Cohen's d (pooled SD, direction: full better) >= 0.8
  - Welch t >= 2.75 (approx. one-sided p < 0.01 at df >= 15)
An item passes iff every listed comparison passes. If a control's SD and the full SD are both 0,
d is reported as +inf when full is better, else fails.
Butlin indicator fails if it has no ablation (no causal path) or any random control is not beaten.
Framework falsifiers: as given in the spec; multi-part falsifiers need every part to pass.
Thaler inverted-U: score(mid noise) must beat score(low) AND score(high) by the criterion; valence-steered
learning must beat shuffled-valence learning by the criterion.
CQM-25 categories:
  Bounded test evidence     = all comparisons pass
  Mixed or restricted       = at least one comparison passes and at least one fails
  Implementation identified = mechanism exists and runs but no controlled comparison is meaningful
  Not established           = no comparison passes, or no mechanism
These are functional indicator tests on the creature's core modules, not evidence of consciousness.
No aggregate consciousness score is computed.
Criteria are never loosened after seeing results.
