## 0. Power and the seed set (change disclosed)
- **New test seeds: 1016–1063 (n = 48).** None of them was used in any earlier round, for tuning or testing.
- The old test seeds 1000–1015 are retired. Every earlier result (v3.1 to v3.8a, n = 16) stays on record unchanged and is not re-scored.
- The pass rule is the same as before:
  - d ≥ 0.8 and Welch t ≥ 2.75 against every control;
  - a bounded metric whose mean is above 0.95·max fails (non-ceiling rule).
- **Disclosure:** with n = 48, Welch t is about 1.7× larger than at n = 16 for the same d. The t-criterion is therefore easier, so d ≥ 0.8 becomes the binding criterion for most items. The thresholds were not adjusted to compensate. Results at n = 48 are not directly comparable to the n = 16 verdicts.
- **Freezing rule on dev:**
  - Dev seeds 2000–2031 are pooled (two 16-seed blocks).
  - A new mechanism is frozen ON only if:
    - its pooled d ≥ 1.0 against the control;
    - its d is ≥ 0.8 in each block; and
    - no currently passing item drops below threshold on pooled dev.
  - Otherwise it ships OFF (parameter 0).

## A. Starvation terminal phase (task 6). Frozen M39 = { ketPS: 0.5, fCrit: 20, p3K: 3, mDeath: 60, lipE: 0.5, xsW: 0, xsSig: 0.5, tdIter: 0, evQ: 0, vK: 0 }
- **Ketone protein sparing.** Proteolysis is multiplied by 1/(1+ketPS·ket).
- **Randle substrate order** in muscle: FFA, then ketones, then glucose. The brain's ketone share is min(0.7, 0.3+0.05·ket).
- **Lipolysis capacity scales with relative fat depletion:** (fSet/fat)^lipE, capped at 4.
- **Phase-III proteolysis.** Below fCrit fat, proteolysis is multiplied by p3K.
- **Death cause.**
  - Death now comes from protein depletion / organ failure: muscle (body protein) below 60, i.e. ~50% of the reference 120 (Cahill 2006; ~50% protein loss is lethal).
  - The old hypoglycaemia rule stays in force as a separate cause.
- **Dev check (seeds 2000–2007).** Death came at about 6.7–7.0 days, after fat exhaustion (fat about 12–15 at death), from organ failure. VIAB-a/b/c all pass.
- **Viability test:** viability_v39.ts, judged by viab_eval_v39.py (frozen). The rules are the v3.8a rules, plus these two requirements on (b):
  - the fat-exhaustion stage (fat < 10% of fat0) occurs between ketosis and death;
  - deathCause is "protein depletion".
- **Viability seeds:**
  - starve and refeed: test seeds 1016–1063 (n = 48);
  - steady state: seeds 1016–1021 (6 dome runs; the evaluator uses min(n, 6), as in v3.8a).

## B. CQM01 heredity (task 2): CQM01R, key C01R (tests_v39.ts)
- **Correction of the Round 19 report.** Round 19 said CQM01 failed because "too few deaths". That is wrong. The evo() design is generational: births do not depend on deaths.
- **Actual cause.** The founders start at fat0 = 60, 85% below the v3.8 set point. The leptin-like forage drive therefore saturates the forage probability at 1 for every genome. The heritable trait then has no variance, and corr() is degenerate (control = 1.0, a constant-vector artefact).
- **CQM01R:**
  - Same design otherwise: 8 generations × 720 ticks, offspring from the best-balanced half, and the same mutation.
  - Founders and offspring start at fat0 = 0.9·fSet = 360, so the genetic forage factor is expressed.
  - corr returns 0 for constant vectors.
  - Arms: full vs offspring genomes random.
- The design was fixed before any dev result of C01R was read. The original CQM01 stays on record and is still run.
