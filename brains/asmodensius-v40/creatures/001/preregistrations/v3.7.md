# Preregistration v3.7: NMDA late recurrence under inhibitory stabilisation, dendritic plateau, depletion forward model, R-variants with non-ceiling metrics

Status: written in Round 18 after tuning on seeds 2000..2015 only. It is committed with the frozen v3.7 code BEFORE any run on test seeds 1000..1015. All earlier results stay on record unchanged. `ORG_MIND=v36` reproduces v3.6 bit-for-bit (state hashes c8dde3bc6744… for v36 and b825387775e0… for v35 are unchanged).

## A. Mechanisms (`mind: "v37"`, the new default). Frozen M37 values:
`{slowK 0.2, inhG 10, dendK 1, dendVh 0.5, dendVs 0.15, tdLr2 0, bmW 0, igTau 300, dLr 0.2, dTau 240, depW 1, fbW 0.2, fbS 1}`

1. **Slow NMDA-like recurrence at sub-saturating gain.**
   - Strength is slowK = 0.2.
   - It is stabilised by divisive inhibition, sdiv = 1/(1 + 13·inhG·modAct), on CTX cells.
   - A slow component (fbS) is added to the CTX→THAL feedback.
   - Higher slowK with weaker inhibition drove RPT-1 to chance on the tuning seeds.
2. **Dendritic plateau (RPT-2).** It is added to the somatic input (dendK 1). On tuning it was weak: d ≈ 0.25 alone, and −0.18 combined.
3. **Depletion forward model (AE-1, activeInference).**
   - Depletion strength dDelta is learned by regression.
   - The believed depletion of a site, dHat, is set to 1 on a reward and decays with time constant dTau.
   - Beta failures are discounted by expected depletion.
   - Expected-free-energy choice multiplies both the pragmatic and the epistemic terms by the believed availability.
4. **HOT-3.** A workspace-ignition feature is added to the confidence model (weights meta3).
5. **HOT-1.** Learned confidence-gated top-down precision is implemented. It is OFF (tdLr2 = 0) because it did not help on tuning: d 0.12, 0.07 and −0.07 at learning rates 0.05, 0.2 and 1.
6. **Page PRNG.** src/build.sh keeps the organism's snapshot-capable mulberry, so a Page snapshot carries the RNG state. Verified identical on 4/4 seeds.

## C. thaler9 non-replication (honest account)
The v3.6 prereg figure (0.402 vs 0.299, d 1.79) came from a tuning directory (sw6/base) produced by code that was later changed before the freeze. It was therefore never a measurement of frozen v3.6.

Frozen v3.6 on the tuning seeds gives d 0.05. Other seed blocks give d 0.01 (seeds 3000), 0.06 (4000) and 0.01 (5000).

Ablations of the v3.7 code on the tuning seeds:
- fbW=0: d 0.02
- visK=0: d 0.00
- lcThr off: d 0.04
- neK=0: d 0.05
- schLam off: d 0.00
- **efeK=0: d 2.33, t 6.59 (0.421 vs 0.301).**

The v3.6 information-gain epistemic drive (M36.efeK 2) dominates exploration and masks the novelty that dream recombination contributes. The pre-v3.6 tuning number was obtained before that drive existed. efeK is NOT changed in v3.7: activeInference relies on it, and tuning a knob away to rescue one item would be selection on the outcome. thaler9 is predicted to fail.

## D. R-variants (originals stay on record)
- **K1aR / K1cR.** The K1 protocol with the degraded HOT-2 stimulus. Original K1 sits at the ceiling (clean one-hot stimuli). Controls: v3.1 cortex and no STDP.
- **CQM03R.** EVO population; metric is |corr(food[0..6], births[1..7])| at one preregistered lag. The control draws random birth counts (2..8). This replaces a control whose correlation is 0 by construction.
- **CQM04.** No mechanism. Reach costs ATP by design, so this is test economics and is reported as such.

## E. Pass rule
Unchanged: d ≥ 0.8 and t ≥ 2.75 against every control, and the non-ceiling rule (a bounded metric with mean > 0.95·max fails). Results go to results/organism_v37.{json,txt} via organism/summarize_v37.ts (directory results/v37_parts).
