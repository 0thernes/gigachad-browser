# Preregistration v3.5: metacognition, agency and interoception mechanisms on the integrated organism

Status: written during Round 16 tuning (seeds 2000..2015 only). It is **committed together with the frozen v3.5 code BEFORE any run on test seeds 1000..1015**. Unlike v3.4, this plan was written after mechanism work had started on tuning seeds; that ordering is disclosed here. The thing that matters for confirmatory status still holds: no test-seed data existed when it was written. v1..v3.4 results stay on record unchanged.

## 0. Diagnosis (tuning seeds only)
- **The organism falls asleep mid-protocol.** Long protocols (HOT-2, HOT-3, C14) run past t≈1000–1260. There S≈0.68 plus evening melatonin crosses the flip-flop threshold, and the organism enters N3. Accuracy in the scored windows then drops to chance. This, not the metacognition readout, was the main cause of the v3.4 HOT-2/HOT-3 failures.
- **HOT-2.** The v3.4 confidence readout saw only margin, greedy flag, NE and S, so it could not track accuracy.
- **CQM09.** The NLMS glucose regression predicted a fall after a meal: it was noisy, and the features were collinear. Its error was worse than persistence.
- **C14 / AE-1.** The action policy collapses onto one stimulus-independent action (p≈0.99) under success-only reinforcement.
- **RPT-2, CQM06.** No conjunctive (cross-module) units exist.
- **activeInference.** The EFE epistemic weight was scaled by volatility and was near zero in most states.

## A. Mechanisms (option `mind: "v35"`, the new default; `mind: "v34"` / env ORG_MIND=v34 reproduces v3.4 exactly)
1. **Orexin-like arousal.** Sustained sensory engagement raises the sleep threshold (thrS = 0.62 + orxK·orx), following Saper et al. 2010. S keeps accumulating, so the sleep debt is paid later.
2. **Higher-order confidence monitor (HOT-2/3).** A second-order logistic readout over first-order states: chosen-action probability, margin, winner posterior, evidence amplitude, greedy flag, NE and adenosine. It is trained by normalised delta on correctness.
3. **REINFORCE actor (AE-1, C14, ual).** A policy-gradient update on the broadcast-driven actor, using reward set by the environment and a running baseline. It adds a marginal-entropy (action-diversity) regulariser that penalises collapse onto a single stimulus-independent action.
4. **Precision-weighted generative top-down (HOT-1).** The percept is a blend of bottom-up reconstruction and the posterior mean of learned class prototypes. The likelihood is Gaussian, with noise variance equal to the learned reconstruction error.
5. **Insula causal model (CQM09).** Predicts the 30-min CHANGE in glucose from physiology (residual on persistence). It is fitted by exponentially-forgetting recursive least squares instead of NLMS.
6. **Cross-module coincidence synapses (RPT-2, CQM06).** Sparse kind-3 CTX→CTX synapses between modules, on a separate RNG stream and lesionable.
7. **Expected free energy (activeInference).** The epistemic weight is efeK·(…) and no longer scales with volatility.
8. **Pearce-Hall associability (ual).** Plus UAL trace constants exposed.
9. **Sleep consolidation (thaler9, CQM12).** NREM factor-model consolidation passes; REM recombination writes over all unexperienced sites.
10. **Sensory-contrast salience** for workspace ignition.

## §F Frozen constants, deviations, tuning outcome (written 2026-10-29 BEFORE any test-seed (1000–1015) run)

**Frozen constants** (organism.ts `M35`): `{ tdPrior 0, tdS 1, entK 1, rlsLam 0.9995, tdBeta 8, tdGain 0.5, confLr 0.2, pgLr 0.3, xW 2, xP 0.05, featIt 4, salK 1, orxK 1.2, salSens 1, remAll 1, remLr 0.25, lrBase 0.1, lrVol 0.4, efeK 0.6, efeTau 200, efeVis 0.5, ualLr 0.3, ualLam 0.8, interoLr 0.3 }`. The env override `V35TUNE` was used for tuning only and is not set for test runs. `ORG_MIND=v34` was re-checked on tune HOT1 and reproduces the v3.4 arms exactly.

**Deviations from §A (all decided on tuning seeds only):**
1. A4 HOT-1: fusing the cortical prior with the Gaussian likelihood hurt on every setting tried (16-seed HOT1 sweeps; full −0.088 to −0.106 vs lesion −0.086). It is frozen with the cortical prior OFF (`tdPrior` 0, likelihood-only posterior) and the blend weight halved (`tdGain` 0.5). HOT-1 is expected to fail.
2. A3: per-trial entropy regularisation lowered HOT-3 accuracy (0.64 → 0.55). It was replaced with a marginal-entropy (running mean policy) regulariser, entK 1.
3. A7: a time-since-visit epistemic term with no visit discount (efeVis 0, efeK 1.5) raised AINF d to ≈0.45. It also dropped AE-1 (d 0.39) and thaler9 (d 0.69), so the frozen value is efeK 0.6 / efeVis 0.5, and activeInference is expected to fail.
4. A6: cross-module synapses were sparsified and strengthened (xP 0.15→0.05, xW 0.6→2). Best tuning: RPT-2 d 0.59, CQM06 d 0.95 / t 2.68. Neither passes on tuning seeds.
5. Pearce-Hall base rate lrBase 0.02 → 0.1 (AE-1 tuning d 1.13 at efeK 0.6; it is borderline across configurations).
6. CQM04 (reach gene) and CQM12: no new mechanism; expected fail. The EVO tuning run was stopped (40 min/run) and is not tuned.

**Tuning outcome** (seeds 2000–2015, near-final build at efeK 1.5): Butlin 9/14, frameworks 5/10, CQM 14/25 excluding EVO items (v3.4 tuning: 7/14, 6/10, 16/25 with EVO). Gains: HOT-2, GWT-2, GWT-4, ual, CQM09, CQM14. New non-ceiling failures from a better, awake organism: GWT-3, ctm, CQM08. They are not dodged.
