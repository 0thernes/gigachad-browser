# Preregistration v2.7: tests for the benchmark capability classes not yet covered (B, S, R, C), and the AST-1R bound

Frozen 2026-10-29 (Europe/London). Committed before any v2.7 test code was written or run on test seeds 1000..1015.
v1..v2.6 are unchanged. Pass rule for every test: Cohen's d >= 0.8 and Welch t >= 2.75 vs EVERY control (frozen v1 compare()), SEEDS 1000..1015.
Mechanism parameters may be set on tuning seeds 2000..2015 only and are frozen in the code commit before the first test-seed run.

## AST-1R (no new test, no addendum)
A bound is computed before any mechanism change. Seed 3012 at base 3000 has drift d > 1 (actuator limit) for 55 consecutive steps. The
drift path does not depend on the policy. A clairvoyant controller that knows the whole future drift and has noise-free observations
(projected-gradient QP, harness/ast_bound.ts) still has mean a^2 = 6.13 on that seed. With every other seed left at the current
Kalman value, d < 0.9 and t < 2.75 vs noschema. The Kalman filter + certainty-equivalent controller is MMSE/LQG-optimal for the
other seeds. So no causal mechanism can pass frozen AST-1R at base 3000. It stays FAIL.

## CAP-B Embodied contact physics (benchmark class B)
Body: a 2D chain of 6 point masses (mass 1) linked by axial springs. Each mass also has a bending spring at the interior joints.
Gravity is g = 9.8. The ground at y = 0 gives a penalty contact (k 2000, damping 20) and regularized Coulomb friction mu = 0.6 x normal force.
Bristle-like anisotropy: mu_back = 3*mu, mu_fwd = mu. The integrator is semi-implicit Euler, dt = 0.002, for 20000 steps.
Actuation: a CPG with one phase per segment, phase lag 2*pi/5 per segment, frequency 1 Hz. It modulates the axial rest lengths (+/-20%)
and the bending rest angles (+/-0.3 rad). Seeds perturb the initial positions (+/-0.01) and the CPG start phase (stream mulberry(seed*263+2701)).
Metric: forward x-displacement of the centre of mass.
Controls: (a) uncoordinated gait: per-segment phases drawn at random (stream mulberry(seed*263+2702)); (b) no contact friction
(mu = 0; contact normal force kept); (c) isotropic friction (mu_back = mu_fwd = mu).

## CAP-S Social learning by observation of a second creature (benchmark class S; roadmap 13)
World: the v2.6 maze (v26mech maze, stream mulberry(seed*251+2751)). A second creature (the peer) walks from start to goal.
Trained peer: it knows the maze and takes the shortest path. The observer adds every transition it sees the peer make to its own world model
(open edges), then seeks the goal with the v2.6 planner (cap 2000).
Metric: -(observer steps to goal).
Controls: (a) random peer: the observer watches a random-walking peer for the same number of moves as the trained peer's path
(stream mulberry(seed*251+2752)); (b) no peer.

## CAP-R Self-reproduction of the full creature state (benchmark class R; roadmap 4)
Parent state = genome seed + the developed weight matrix of its network (v2.5a cqm21rNet) + organ state (circadian phase,
habituation level, lineage hash head). The parent writes a self-description as bytes (float32 weights + state). The description goes
through a noisy channel (independent bit flips p = 1e-3, stream mulberry(seed*263+2711)). The child decodes it with the creature's
repair mechanism, a triple-redundant description with a bitwise majority vote, and rebuilds its state.
Metric: fraction of state entries (36 weights + 6 biases + 3 organ values) that the child reproduces bit-exactly.
Additional: mean fidelity >= 0.99.
Controls: (a) random-init child (fresh creatureNet of a different seed, same organs reset); (b) single-copy description (no repair) through the same channel.
Caveat stated up front: replicating a description is close to pass-by-construction. The test shows the full learned state is carried,
which the procedural genome alone does not do.

## CAP-C Connectome-grounded controller (benchmark class C; roadmap 7)
Data: the C. elegans hermaphrodite connectome edge list (OpenWorm c302, herm_full_edgelist.csv, committed in creatures/001/data/; from
https://raw.githubusercontent.com/openworm/c302/master/c302/data/herm_full_edgelist.csv). Neurons and muscles appear as listed.
Model: a rate network over all nodes, x_i <- clip(x_i + (dt/tau)(-x_i + relu(sum_j W_ij x_j + G_i + I_i + noise)), 0, 1),
with dt/tau = 0.1 and noise sd 0.05. Chemical weight = 0.02 x count, with a negative sign when the presynaptic cell is GABAergic
(DD*, VD*, RMEL/R/D/V, AVL, DVB, RIS) and positive otherwise. Gap junctions add 0.01 x count x (x_j - x_i).
Stimulus: anterior touch = input 1 to ALML, ALMR, AVM; posterior touch = input 1 to PLML, PLMR. Each trial runs 300 steps from zero;
readout = mean(AVAL, AVAR) - mean(AVBL, AVBR) over steps 200..299 (backward-command minus forward-command).
Per seed: 20 anterior and 20 posterior trials (noise stream mulberry(seed*263+2721)).
Metric: AUROC of the readout separating anterior (expected backward) from posterior trials.
Control: degree-preserving shuffled connectome. Within each synapse type, the target column is randomly permuted, which keeps the
in/out degree sequences and the weights (stream mulberry(seed*263+2722)). Additional requirement: mean AUROC > 0.5 (correct direction).
No parameter of this model may be tuned for this test. The values above are fixed now.
