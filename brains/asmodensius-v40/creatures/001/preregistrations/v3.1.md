# Preregistration v3.1: CQM-25, Butlin-14 and 10-framework indicators re-run on the integrated organism

Status: **PLAN, committed before any v3.1 code was written** (2026-10-29). A frozen addendum (§F) with exact protocol constants will be
appended after tuning on seeds 2000..2015. It will be committed **before** the first run on test seeds 1000..1015. Every change from this plan
will be listed in §F with a reason. v1..v3.0 results stay on record unchanged. That includes the v3.0 C2/C8b failures and the CAP-C reversed-direction failure. No sign flips.

## A. System under test
`creatures/001/organism/organism.ts`, the same file the browser bundles. Every item drives the organism through its sensory lines (`sens`, 16 lines = 4 modalities × 4)
and/or its body/world interfaces. Every item reads behaviour or internal state from the organism. The harness models in harness/harness.ts are NOT used as systems under test.
Only harness `compare()`, `item()`, `auroc()` (statistics) are reused. Mechanisms added in v3.1 live inside organism.ts in a `Mind` layer. That layer is stepped by
`Organism.step()`, reads the spiking CNS (module rates), neuromodulators and sleep state, writes back into neural drive, LC/DA and ATP cost, and has a lesion switch per mechanism.

## B. Pass rule (unchanged from v3.0)
Cohen's d ≥ 0.8 and Welch t ≥ 2.75 vs EVERY listed control, 16 seeds per arm, test seeds 1000..1015.
- **Non-ceiling rule (new):** for bounded metrics (accuracy, AUROC, fractions), the full condition's mean on test seeds must be ≤ 0.95 of the attainable maximum. If not, the item FAILS as "ceiling".
- **Controls:** each control is a functioning organism with ONE mechanism lesioned. It is never a null policy. Exceptions are marked (S) for shuffled-label controls.
- Tuning only on seeds 2000..2015. Rollup `butlin14` passes only if all 14 Butlin items pass.
- CQM 23 and 25 are "Implementation identified" (no d/t), as in v1. CQM 24 is a tolerance test (bit-identical state hash).

## D. Honesty constraints
Items marked "= X" share data and must not be counted as independent evidence. Several controls lesion the exact mechanism the metric needs (e.g. GWT-3), so a pass
shows the mechanism works inside the organism and is causally necessary. It does not show anything about consciousness. No aggregate score.

### §F frozen addendum (2026-10-29, written after tuning on seeds 2000..2015 and before any run on test seeds)
The code is frozen at the commit that adds this addendum. Its tests are `organism/tests_v31.ts` and its runner is `organism/run_v31.ts`. Tuning outputs are in `results/v31_tuning/`.

**Deviations from the plan:**
- **Sensory pathway constants.** TUNE = {thal 0.1, ctxDrop 0.35, st 3, tc 5, rec 0.2, sensIn 1.5}. In v3.0 the cortex was saturated (≈0.6 spikes/substep), and topographic input was not expressed. Excitatory CTX baseline drive was lowered by 0.35.
- **Bug found and fixed (v3.0 code).** The `add("RAPHE", …)` call sat inside a line comment, so raphe had no drive (5-HT ≈ 0) in all v3.0 results. It is fixed when `decision !== "v30"`, so the fix applies to v3.1/v3.2. v3.0 results stand as recorded, with this caveat.
- **UAL value learning.** The TD step was changed to a normalised (NLMS) step. The unnormalised step diverged on tuning seeds (V ≈ 1e171).
- **CQM-01..04 population runs.** Settings: 8 generations, cap 8, life 720 ticks, food pool regen 160 kJ per generation. A non-finite energy balance is scored as −1e3.
- **CQM03 control caveat.** In the fixed-birth control the population is constant, so the correlation is 0 by construction. The control is therefore weak.
- **06 control.** The planned "mixLesion" control was replaced by "integration lesion, modality 0 only" (a decoder sees module 0 only).
- **13 = HOT-2.** 19 = RPT-1, 20 = GWT-3, 21 = iit4 (reported once, not as independent evidence).
- **ctm** uses the same broadcast lesion as GWT-3. **sensorimotor** and **projective** share the efference mechanism. AE-2 uses a separate `fwdLesion` control (gain fixed at 1).
- **Decoders.** Decoders called "probe" in tests (GWT-1 per-task decoders, RPT-2 XOR, C06 estimator) belong to the test, not to the organism.

**Tuning-seed outcome (honest, recorded before the test run).** The cortical-classification items stayed at chance after tuning: RPT-1 0.24, GWT-2 0.24, GWT-3 0.26, HOT-2 AUROC 0.47, CTM 0.36, C14 0.25. The spiking cortex's module rates over a 6-substep tick do not carry stable class information that a delayed or broadcast readout can use. No further tuning was attempted, and these items are expected to fail.
