Tsotchke Diffusion · Chaos Mode

A tiny diffusion model running entirely in your browser (loading...). Nothing is uploaded anywhere.
About (honest version)

This is a from-scratch ~1M-parameter DDPM (a small UNet, 64×64 pixels, 400 noise steps) trained on a CPU. The unconditional model saw 6 images; Chaos Mode was fine-tuned from it on 11 images, each labelled with one random Unicode character and given its own learned 128-number embedding (plus a "null" one for classifier-free guidance). With so few images it mostly memorizes and remixes their colours and textures: expect texture soup and glitches, not objects. Cranking guidance, sum-blend, noise and extrapolation deliberately pushes it off the rails.

Randomness: in this page all randomness (the random chaos string, the per-character weights, the starting noise) comes from your browser's crypto.getRandomValues seeding a small PRNG. It is not Tsotchke QRNG. The presets in the dropdown were precomputed on Linux with the Tsotchke quantum_rng C library, which is a classical, deterministic simulation of quantum-measurement-style mixing, not real quantum randomness. Presets fix the string, weights and seed, but the pixels still differ from the Python app, because the browser uses its own Gaussian generator.

Other Tsotchke pieces in the desktop app (neuro-inspired layers, a tensor-logic connectome, an Eshkol-computed schedule) are not used by the two models on this page; both are plain UNets. The model runs via onnxruntime-web (WebGPU if available, else WebAssembly). The browser sampler matches the PyTorch sampler to about 1e-4 (max abs) in a deterministic test.
