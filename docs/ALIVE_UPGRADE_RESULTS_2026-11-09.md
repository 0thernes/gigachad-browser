## Observable behavior changes

1. **Page exploration follows actual progress.** One scroll owner measures
   viewport position, acknowledges displacement, waits for smooth motion to
   settle, detects repeated blocked commands and recognizes the bottom of the
   document. Stride responds to the controller and viewport. Exhaustion feeds
   navigation readiness; trusted page input yields control to the user.
2. **Both split panes participate.** The visible shared creature is constrained
   to the actual pane geometry. Each ready document supplies its own bounded
   observations and colliders. Reloads, authority changes, split resizing and
   Pause invalidate stale geometry and retained callbacks. Secondary observations
   do not create a false primary-navigation reward.
3. **Navigation recovers sooner.** The application configures a five-second
   reading dwell, 2.5-second settled dwell and ten-second dispatch timeout.
   Unchanged content needs repeated observations spanning at least 3.5 seconds;
   exhausted or blocked viewports provide a separate signal. These are scheduler
   targets, not hard wall-clock promises. Redirects cannot continually reset the
   dispatch deadline. Frontier restore preserves its full supported capacity.
4. **Learning and model evidence are attributable.** Precision inputs require
   actual completed kernel receipts. Reward baselines reset across authority
   epochs. Replay does not join unrelated tab/epoch transitions, and held-out
   transition membership survives rolling windows. Feeding offers pellets;
   actual contact earns simulated consumption and reward.
5. **Inspectors report their evidence.** Missing values remain unavailable;
   zeros, false values and negative results stay visible. Generated hypotheses
   do not increment a proven-theorem counter. Encoded-CNF satisfiability is scoped
   to its assumptions. Decorative Deity features are labeled local simulation
   values. Global zero-LLM headlines disclose the optional configured research
   model. Formation displays the actual returned formation name. Runtime ticks
   are distinguished from the old legacy portal-attempt counter.
6. **New native checkpoints preserve future behavior.** The adapter restores the
   saved sparse graph, developmental affinity values and shared Set identities.
   Authored projection regions, adjacency, shape, checksum and alias consistency
   are validated before replacing state. Donor sources and generated bundle are
   unchanged. [Native replay report](ALIVE_AUTHENTIC_REPLAY_2026-11-09.md) and
   [projection/alias repair](ALIVE_AUTHENTIC_PROJECTION_ALIAS_2026-11-09.md).

The existing normal profile's revision-128 native envelope lacks the developmental
affinity field. An isolated read under Electron 45 rejects its reconstructed graph
shape before replacing candidate state. The canonical payload hash was verified,
and an exact backup was made beside it before normal-profile upgrade work.

dry run on the actual old canonical record preserved tick 51,370, 3,480 edges,
all saved native/RNG/collection state, and prepared 645 reconstructed affinity
rows. The candidate imported/exported exactly and completed 30 later developmental
sprouts. The canonical file was unchanged, and no candidate payload was exported.
Seventeen focused tests and a new three-seed exact normal-path Electron proof
pass. This additional API postdates the captured operational snapshot and has
separately identified hashes and tests. [Legacy recovery contract](ALIVE_AUTHENTIC_LEGACY_RECOVERY_2026-11-09.md).

Startup migration is now implemented separately from that initial operational
snapshot. It preserves an exact verified backup bound to the source revision and
digest, validates a detached candidate, publishes through the canonical store and
records recovery provenance before renderer bootstrap. Its isolated two-process
qualification is recorded in [native startup recovery](ALIVE_NATIVE_STARTUP_RECOVERY.md).
Recorded weights, graph, scheduler and known state are preserved; never-saved
developmental affinity remains explicitly reconstructed rather than historically
exact. An isolated copy-based proof does not establish that the user's already
running normal session was migrated.

The ordinary genome remains a declared partial learned-state payload. A CID
checkpoint's observed tensor roster depends on which dynamic models exist at
capture; a fixture's 560 tensors are not a universal complete-model census.
New generic learned-state codec/registry tests do not establish that the normal
app already persists every optimizer, replay buffer or dynamic component.

The eight Humunculus gates remain unqualified until their specified experiments
exist. In particular, unseen-task navigation gains, independent training-seed
learning comparisons, full FlyWire reproduction, physical quantum execution,
external Eshkol execution and independent-peer handoff have not been established.

The Tor result proves the tested onion document and route. It does not certify
arbitrary onion reachability, Tor Browser privacy protections or global anonymity.
Useful broad-web research still needs task-based discovery and factual-retrieval
evaluation, beyond counting novel domains or changing weights.
