# ALIVE integration release — November 9, 2026

This release connects adaptive exploration, the visible split-pane body,
numerical model contributions, measured learning, optional model research and
managed Tor navigation through the ALIVE runtime. It also repairs persistence
and asynchronous startup/training boundaries. These are functional software
changes; sentience, omniscience and the proposed eight scientific gates are not
qualified outcomes.

## User-visible changes

- Viewport exploration measures actual movement and page progress, coordinates
  one scroll owner, yields to user interaction and detects blocked/exhausted
  pages. Dispatch-based navigation deadlines prevent stalled loads from owning
  exploration indefinitely. Novelty and domain history influence research.
- Page observations distinguish authored content from the creature's generated
  annotations. Visual badges and Zalgo decoration must not lengthen source link
  labels until otherwise valid navigation targets disappear from discovery.
- The creature is projected in both visible split panes with separate document
  observations and correctly clipped bounds. Reload, resize, tab changes and
  Pause revoke stale work.
- Fourteen numerical adapters and five selected specialist contributions feed
  bounded control. Completed computations, parameter updates and actual
  downstream influence have separate evidence. Simulated physiology and body
  morphology affect the controller; visual labels do not substitute for those
  mechanisms.
- Configured language-model inference proposes research goals and queries.
  Availability and model identity are reported honestly. Tor routing uses actual
  transport and current-document receipts; an open proxy port or a decorative
  onion URL cannot count as a loaded onion document.

## State, startup and training

- The authentic Asmodensius envelope retains native graph, RNG, collection alias,
  scheduler and developmental-affinity state. Legacy recovery preserves known
  fields and explicitly labels missing historical affinity as reconstructed.
  The migration backs up and validates the canonical record before publication.
- Exact primary persistence stores six Float32 views, 718 values and two cortex
  aliases. Actor/world frozen baselines remain distinct. The remaining legacy
  genome is a separately scoped partial payload.
- Native prepared imports validate private candidates and live destination
  identity before synchronous installation. Stale or copied handles, malformed
  vectors and changed destinations reject without partial installation. The
  API alone does not establish atomic restoration across every model component.
- Ordered startup validates state before activating the main script, owns early
  shutdown, prevents cancelled scripts from executing, and checks late boot
  continuations. Asset responses use generation and source receipts.
- Fixed renderer-owned arenas preserve their views and offsets. Worker training
  admits replies only for the current worker, generation, job and semantic
  target epoch. Pause, visibility, restore and shutdown invalidate stale work.
  The worker semantic clock is not yet part of a complete durable model catalog.
- The independent hydration observer copies bytes and metadata before invoking
  production export code. A regression test ensures export-time repair cannot
  hide an incorrect loaded state.

## Release validation

Final release-candidate results are recorded in
`docs/verification/release-2026-11-09.json`. The public record contains test
counts, runtime versions and source identifiers, without browser profiles or
private page captures. Raw diagnostic archives remain local.

The qualification sequence is the complete portable Node suite, the required
Python/Node/Electron smoke checks, an isolated actual-worker proof, an integrated
split-pane/performance run followed by bounded real public navigation, and a
smoke launch of the portable Windows build. The public phase requires uncached
successful main-frame responses, current document authority, measured research
tensor changes and complete Pause settlement. The legacy offline portal mode
does not support the current research policy, which excludes loopback targets;
its unsuccessful diagnostic is retained separately and is not a navigation pass.
Earlier native replay, local
inference and real onion results qualify their recorded source versions and
network conditions; they are not substituted for later changed-source checks.

## Running and building

Use Node.js 22.12.0 or newer (Node.js 24 matches CI) and Python 3.11 or newer. `npm ci` installs the pinned
Electron 45.2.3 and build dependency. `npm run test:all` discovers all direct
`tests/*.test.cjs` and `scripts/*.test.cjs` suites, including independent evidence
tests. `npm run smoke` additionally checks the sidecar and isolated Electron
startup. CI runs the portable suites on Windows and Linux.

On Windows, `npm run build:portable` packages Git-index source paths with the
pinned installed Electron runtime into a new directory under `dist/`. It checks
source/destination hashes, preserves licenses, rejects path escapes and existing
output directories, and excludes local settings, credentials, profiles and raw
research captures. This follows Electron's documented
[manual application packaging](https://www.electronjs.org/docs/latest/tutorial/application-distribution).
The executable is unsigned. Python, language-model services, model weights and
Tor remain external dependencies. The build does not start or alter an existing
browser session.

## Remaining research and persistence scope

The full learned-state catalog is still incomplete. Optimizers, replay,
recurrent/private closure state, curriculum, RNG ownership, model families and
cross-component atomicity require further explicit schemas and qualification.
Exact primary tensor restoration must not be described as full model continuity.

The Humunculus gates require independent backend parity, deadlines, unseen-task
navigation, multi-seed retained learning, curriculum ablations, peer handoff,
speech and body/connectome transfer experiments. Those gates remain unqualified.
Physical quantum execution, external Eshkol execution and biological FlyWire
equivalence are not established. Browser research does not fine-tune the
configured language model.
