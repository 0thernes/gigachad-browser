## Non-negotiable invariants and evidence rules

Guest pages remain webviews without Node integration, and privileged chrome calls pass through the preload bridge and validated sender/frame/document/arguments. Local-only intent cannot silently become cloud egress. A failed sanitizer cannot authorize unsanitized text, and screenshots require the declared image policy. A model label is unavailable until actual loading supports it. Exact integers must not pass through inexact JavaScript Number representations. Original algorithms, practical approximations, research hypotheses and scientific metaphors retain different labels.

Persist complete continuation state before claiming restart parity. Reject wrong schema/source/type/shape/integer/corruption atomically. Measurement records identify producers, units, scope, time and missing/fallback/stale states. Requirements start NOT_RUN; PASS needs direct applicable evidence, N/A needs rationale and never counts as PASS. Source/dependency/config/environment changes invalidate affected evidence until justified revalidation. Source scans and static labels never substitute for security or learning behavior.

The 500-control target counts distinct justified requirements, not 50 predicates repeated ten times. Ten editorial prompt versions do not count as engineering cycles. Each of 250 entries in [CYCLE_REVIEW_LEDGER.json](CYCLE_REVIEW_LEDGER.json) must retain actual reviewer, revision, examined contracts, findings, evidence, remediation and disposition. A cycle completes only with substantive outcome and exit decision, not because the ledger has rows.
